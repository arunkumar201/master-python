# master-python

Python interview prep — LeetCode solutions , Python and DSA problems.

## Structure
- `leetcode/` — LeetCode problems (`lc_27.py`, `lc_326.py`, …)
- `problems/` — standalone problems (`longestSubarray.py`, 
`tower_of_hanoi.py`, …)

## Run

Requires Python 3.12+.

```bash
python leetcode/lc_27.py
python problems/longestSubarray.py
```

Or with [uv](https://docs.astral.sh/uv/):

```bash
uv run python leetcode/lc_27.py
```
